# Story 5.5 — Dashboard de Analytics de Cliques

## Status

**Ready for Review** — implementada pelo `@dev`. typecheck/lint/test/build verdes; app sobe (HTTP 200 em `/login`). Aguarda QA Gate (`@qa`).

---

## Story

**Como** dono de uma página biolink,
**eu quero** um dashboard que mostre quantos cliques cada link recebeu e a evolução diária,
**para que** eu entenda o que engaja minha audiência e ajuste minha página.

---

## Acceptance Criteria

1. Página `/dashboard/analytics` (server component sob o auth guard) obtém o profile do usuário logado e lista os links numa tabela: título, total, últimos 7 dias, últimos 30 dias.
2. Gráfico de linha inline-SVG de cliques por dia (agregado de todos os links), estilizado com tokens do design system, responsivo.
3. Período seletivo 7/30/90 dias via `searchParams` (`?days=30`), default 30, mantendo SSR.
4. Estado vazio ("nenhum clique ainda") com cópia amigável + CTA para a página pública.
5. Loading state com skeleton (`loading.tsx`).
6. Acessibilidade: `<table>` com `<caption>`; gráfico SVG `role="img"` + `aria-label` + tabela alternativa sr-only; `aria-current` na aba ativa.
7. Aba "Analytics" na nav do dashboard (Perfil ↔ Links ↔ Analytics).
8. Teste unitário dos helpers de derivação (série → coordenadas SVG) + RTL leve de tabela/estado vazio.

## Dev Notes

### Decisões

- **Toggle via `searchParams` (não client).** `PeriodToggle` renderiza `<Link href="?days=N">`; a page relê `searchParams` e reconsulta os helpers no servidor. SSR puro, zero JS de estado, URL compartilhável. `parsePeriod` normaliza para `{7,30,90}` (default 30) e é testado.
- **Gráfico inline-SVG zero-dependência** (guia `dataviz`): série única → sem legenda (o título nomeia o dado); linha 2px em `accent`, área wash ~10%, grid/eixos hairline em `border`, textos em `muted-fg`. A matemática vive em `lib/analytics/chart.ts` (pura, testável); o componente só desenha. `viewBox` fixo + `class h-56 w-full` → responsivo.
- **Empty-state quando `totalClicks === 0`** (soma dos totais por link): substitui gráfico+tabela por cópia amigável + CTA para `/username` (path real sem `@`; exibe `@username`).
- **Authz app-layer reusada** (Story 5.4/3.5): helpers filtram por `profile_id = user.id`; sem RLS no MVP (débito Epic 6).

### Acessibilidade

- Tabela de links: `<caption>` (sr-only) + `<th scope>`.
- Gráfico: `<svg role="img" aria-label="…total…pico…">` + `<table class="sr-only">` com os dados diários (`<caption>`).
- Nav e toggle: `aria-current="page"` na opção ativa.
