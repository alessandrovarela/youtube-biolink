# Story 2.8 — Logout

## Status

**Ready** — Validado pelo @po (Pax). GO 8/10. Liberado para @dev.

---

## Story

**Como** usuário autenticado,
**eu quero** deslogar,
**para que** minha sessão seja encerrada.

---

## Acceptance Criteria

> Fonte canônica: `docs/prd.md` § 6 — Epic 2, Story 2.8.

1. Botão "Sair" no dashboard dispara Server Action que chama `supabase.auth.signOut()`.
2. Cookies de sessão são invalidados.
3. Redireciona para `/` (landing ou login).
4. Tentar acessar `/dashboard` após logout redireciona para `/login`.

---

## Tasks / Subtasks

- [ ] **T1. Server Action `signOut`** (AC: 1, 2, 3)
  - [ ] `lib/actions/auth.ts` → `signOut()` → `supabase.auth.signOut()`.
  - [ ] `revalidatePath('/', 'layout')` + redirect `/`. [Source: architecture.md § 5.2]

- [ ] **T2. Botão "Sair" no dashboard** (AC: 1)
  - [ ] Componente/botão (form action) no shell do dashboard que chama `signOut`.

- [ ] **T3. Verificar invalidação** (AC: 2, 4)
  - [ ] Confirmar que os cookies de sessão são limpos.
  - [ ] Pós-logout, `/dashboard` redireciona para `/login` (depende do auth guard da Story 2.9).

- [ ] **T4. Teste de integração** (AC: 2, 4)
  - [ ] Após `signOut`, sessão ausente; acesso a `/dashboard` redireciona.
